## How I work

| As a data scientist | As a builder |
| --- | --- |
| Start from the business question, then translate model output (SHAP, causal graphs) into stakeholder recommendations | Benchmark before committing: CatBoost vs. LightGBM, YOLO vs. RT-DETR vs. CLIP |

## Selected work

**AIGC workflow (Tencent IEG).** An end-to-end pipeline from asset understanding to controllable image generation: `image tagging → LoRA training → LLM parsing → structured prompt → ComfyUI generation`. Automated tagging cut manual labeling time by 90% across 102 game assets.

**SKU-level ARPU forecasting tool (Tencent IEG).** Structured SKU sales data, benchmarked CatBoost and LightGBM to 0.01 MAE, and packaged the model as an internal prediction service on Tencent Cloud for business users.

**Game-asset monetization drivers (Tencent IEG).** Used SHAP to explain which aesthetic attributes drive monetization, and turned the findings into stakeholder-facing recommendations.

**Causal discovery for predictive maintenance (Bosch China).** Mapped failure dependencies across multivariate time series from 700+ sensors, improving predictive-maintenance accuracy by 25%.

**Inventory chatbot agent (Bosch China).** Built features and engineered prompts on top of an AutoGen multi-agent framework built by teammates, adding retrieval and workflow automation. Query-resolution time fell by 60%.

**UAV palm-tree detection (WFU IRSC Lab).** A deep-learning pipeline for palm-tree detection and spatial analysis in ecological research. I evaluated YOLO, RT-DETR and CLIP, curated 3,000+ annotated UAV images, and fine-tuned YOLOv10 for skeleton prediction in dense canopies.

**Tourist-level clustering (TouringPlans).** Tested whether TouringPlans' 10-level Disney World crowd framework captures real differences in visitor behavior. I applied K-Means and Gaussian Mixture Models, designed a custom cluster-selection score, and presented recommendations in Tableau.

**Equity in post-HCT survival prediction (CIBMTR competition), as team leader.** Built KNN and iterative imputation for heterogeneous clinical data and reproducible scikit-learn feature pipelines. I benchmarked XGBoost, CatBoost and LightGBM with K-Fold CV and a Kaplan-Meier target transformation, and examined performance across racial groups.
